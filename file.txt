Cashfree Integration: Passing PG Charges to
Customer
Objective:
Ensure shop owners always receive their exact service price (e.g., ■100), while the Payment
Gateway (Cashfree) charges are passed on to the customer.
1. Logic for Amount Calculation
- Shop owner price = base_amount (example: 100)
- PG fee = 2% + GST (18% on fee) = ~2.36% effective
- Customer amount to be charged = base_amount / (1 - PG_effective_rate)
Example:
final_amount = 100 / (1 - 0.0236) ≈ 102.36
So:
- Customer pays: ■102.36
- Cashfree deducts 2.36% = ■2.36
- Shop owner gets: ■100 (net).
2. Backend Implementation Steps
Step Description
1 Fetch base amount (service price set by shop owner).
2 Calculate final payable amount using formula above.
3 Send this final_amount to Cashfree API (/pg/orders).
4 Store both amounts in DB: base_amount (shop owner payout) and final_amount (customer payable).
3. Optional: Use Cashfree 'Convenience Fee'
Cashfree can auto-add PG fee to the customer bill. Contact Cashfree support to enable this feature.
If enabled, you only need to send base_amount in API and Cashfree handles the rest.
4. Example Flow (Manual Calculation Method)
Shop owner service price = ■100
1. Backend calculates final amount: ■102.36
2. Customer sees ■102.36 in checkout.
3. Payment goes through Cashfree.
4. Settlement:
- PG fee deducted: ■2.36
- Shop owner receives ■100.
